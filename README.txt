Vitals MBBS Hub — rebuild v3

First launch preloads these editable subjects: General Medicine, General Surgery, Paediatrics, Ophthalmology, ENT, OBGYN, Dermatology, Orthopaedics.
Each subject starts with editable requirements: LECTURE 75%, SGT 75%, SDL 75%, AETCOM 75%, POSTING 80%; any other class type defaults to 75%.

Existing Vitals data is preserved. Defaults are only created when the app has no saved data. Subjects can be edited/deleted in Settings > Subjects & attendance targets. Add more class types by adding lines in the subject editor in the format TYPE: percentage.

Recurring classes, calendar, attendance marking, CSV review/import, backup/restore, reset and themes are included. Excel, PDF and image/OCR import are not implemented yet. Data is stored locally in this browser installation; export backups regularly.
