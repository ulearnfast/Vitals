Vitals MBBS Hub — rebuild preview

This build starts with empty user data. Features: subject management, attendance marking/editing, calendar, CSV import review, import batch undo (preserves marked sessions), JSON backup/restore, reset, seasonal themes, light/dark mode and font selection.

Import currently supports CSV only. Excel, PDF and scanned-image OCR are not implemented in this build. Test on a separate GitHub Pages repository before replacing any existing app. Data is stored locally in this browser installation; export backups regularly.
