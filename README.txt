VITALS MBBS HUB

Upload the CONTENTS of this folder to the root of your separate Vitals GitHub Pages repository, replacing the old Vitals files:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

This build adds the eight requested subjects through a one-time migration. It does not clear attendance, timetable sessions, or other saved data. The migration adds any missing default subjects and preserves existing subjects and category target overrides.

After GitHub Pages updates, open the Vitals website once in Chrome while online and wait for it to finish loading. The service worker cache is versioned vitals-rebuild-v6.
